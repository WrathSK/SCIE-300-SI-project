# SCIE 300 Statistical Inquiry Project


The project investigates changes in course grade distributions at UBC across different academic periods, with a particular focus on the impact of COVID-19 and post-pandemic instructional modes.

## Data Source
The raw grade data used in this project were obtained from the **UBC PAIR Grade Data repository**:

- DonneyF. *ubc-pair-grade-data*. GitHub repository.  
  https://github.com/DonneyF/ubc-pair-grade-data

The original dataset is publicly available and was accessed via GitHub.
